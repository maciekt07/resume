\project%
  {Math Course Platform}%
  {Next.js · TypeScript · PostgreSQL · Redis · Stripe · PayloadCMS}%
  {%
    \linkitem{\faGithub}{https://github.com/maciekt07/nextjs-math-course}{Source}%
    \dotsep%
    \linkitem{\faGlobe}{https://nextjs-math-course.vercel.app}{Demo}%
  }

Full-stack e-learning platform for selling and delivering online math courses, combining a
custom CMS, secure payments, and protected video/media delivery on a production-grade stack.

\begin{itemize}
  \item Implemented full secure Authentication with Google OAuth, One Tap, email verification, block for disposable emails, rate and session limiting with \textbf{Redis} to prevent account sharing
  \item Achieved \textbf{\textasciitilde100} Lighthouse performance score by splitting large Markdown lessons into sections and rendering only visible content
  \item Customized headless \textbf{Payload CMS} for Markdown/LaTeX lessons, added scheduled publishing with \textbf{QStash}, signed/public \textbf{Mux} video streaming, and protected \textbf{Cloudflare R2} images with blur placeholders
  \item Integrated a \textbf{Model Context Protocol (MCP)} server into the CMS, letting AI clients draft, edit, and review content with API-key-scoped access control per collection
  \item Optimized SEO for free lessons: OG image generation and XML sitemaps with per-lesson metadata
  \item CI/CD with GitHub Actions \& Vercel: automated quality checks (dead code, linting, type safety, tests); production deployments blocked on failure
\end{itemize}
